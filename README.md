# GLYPH ASCII Studio

安装：`npm ci`

本地启动：`npm run dev`

Docker 启动：`docker compose up --build`，访问 http://localhost:18018。

类型检查：`npm run typecheck`
采样几何校验：`npm run test:geometry`

## 逐格采样检查与采样校准

在预览区切换到「采样检查」后，可在原图上点选任意格，查看该格的实际采样覆盖范围、
超采样落点与相对权重，并在「全局偏移校准」和「局部平滑校准」之间选择校正方式。

- 所有校准量都定义在**原图像素采样空间**；缩放、滚动、设备像素比（高分屏）只改变
  检查画布的显示变换，不会改变校准数学。
- 全局模式：统一平移采样原点（dx/dy，原图像素），可在图上拖动或用滑杆/1px 微调。
- 局部模式：拖动画布上的节点手柄，相邻格通过双线性插值保持连续。节点拉动可能造成
  区域折叠或采样越界，无效格会以红色斜纹标出并实时计数，存在无效范围时禁止确认。
- 密度或裁剪变化后采样指纹失配，覆盖范围重新推导：局部场直接作废，全局偏移保留数值
  待复核；签名失配期间正式生成不会使用旧校准，也不会用旧采样解释新字符。
- 检查报告区分**原始格色**（名义覆盖）、**校正后格色**（当前草稿实际覆盖）和
  **最终亮度**（经对比度/伽马/反转映射后的字符阶梯值），并同时给出当前网格字符与
  草稿候选字符。
- 确认校准后所有格统一按已确认校准重新采样；取消则丢弃草稿、保留原网格。检查高亮只
  存在于检查画布，图片、纯文本与下载产物均不包含任何检查标注。
